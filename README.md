# 拾译

在 Windows 桌面上选中文字，即可用自己的大模型翻译。双击 **dist\Shiyi.exe** 启动。适用于装有 .NET Framework 4.8 的 Windows 10 / 11，不需要安装开发工具。

## 连接模型

打开右上角的 **设置 → 模型服务**，填写接口地址和 API Key。拾译会自动从该地址的 `GET /models` 读取模型。点击 **选择模型**，输入名称的一部分即可筛选，用鼠标或方向键和回车选中，再保存。也可刷新列表，或直接填写模型 ID。模型列表显示服务返回的全部 ID，翻译时请选择支持 `POST /chat/completions` 的模型。

| 服务示例 | 接口地址 | 模型名称 |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1` | `gpt-4o-mini`，或该账户可用的模型 |
| DeepSeek | `https://api.deepseek.com/v1` | 填写服务商提供的模型 ID |
| 本机 Ollama | `http://localhost:11434/v1` | 填写 `ollama list` 中已安装的模型名 |

也可以填写完整的 Chat Completions 地址。只填域名时，拾译使用 `/v1/chat/completions`。需要鉴权的服务使用 Bearer API Key。无需鉴权的本地服务可以留空。

模型列表使用同一接口前缀和密钥。例如填写 `http://localhost:11434/v1/chat/completions` 时，会读取 `http://localhost:11434/v1/models`。更换服务的协议、主机或端口后，请为新服务填写对应的密钥。服务未提供模型目录时仍可手填模型名称。

## 外观与悬浮窗

在 **设置 → 外观** 中选择浅色、深色或跟随 Windows 系统。可选择拾译、T3 蓝、玫瑰、森林、海洋、余烬和鸢尾配色，也可输入十六进制强调色或点击 **选色**。配色参考了 [T3 Code 的主题色板](https://github.com/pingdotgg/t3code/blob/main/packages/shared/src/themePalettes.ts)。

**悬浮窗不透明度** 可在 20% 到 100% 之间调节，100% 表示完全不透明。设置中的样例会随滑块即时变化，也可以从译文浮窗右上角的齿轮直接调整。点击 **保存设置** 会记住外观，取消或关闭设置会恢复打开前的效果。

## 翻译文字

- **鼠标划词**　在支持 Windows 文本选区接口的应用或拾译自己的原文框里，按住鼠标左键划过文字，松开后选区旁会出现一个 **小蓝点**。点击蓝点，译文就在这段文字旁的悬浮窗里显示。可直接复制译文，也可点击原文区域收起浮窗。
- **快捷键**　用鼠标或键盘选中文字，按 **Ctrl+Alt+T**。如果应用没有开放选区，按浮窗提示在原应用中按 **Ctrl+C**，30 秒内再按 **Ctrl+Alt+T**。此方式只读取这次新复制的文字。
- **手动输入**　在主窗口输入或粘贴原文，选择目标语言，按 **Ctrl+Enter** 或点击 **翻译**。翻译过程中可点击 **取消**。

默认译为简体中文，可在“译文”旁切换目标语言。主窗口关闭后，拾译继续在系统托盘运行。双击托盘图标可重新打开，右键选择 **退出拾译** 可完全退出。也可再次双击可执行文件唤回窗口。

选中单词时，蓝点会打开学习词卡。先看高亮原词的原句和句中义，再看音标、原形（如适用）、各词性的常见义项、搭配和双语例句。例如在 “We sat on the river bank.” 中选中 **bank**，可区分这里的“河岸”和另一个常见含义“银行”。点 **发音** 可用 Windows 已安装的对应语言语音朗读。点 **复制词条** 可复制整张卡片。

选中整句或普通多词片段时，浮窗直接显示译文。手动输入单词、从剪贴板取词或原应用未提供上下文时，词卡会提示缺少原句。语音使用本机语音包，缺少对应语言时可在 Windows 语音设置中添加。

划词依赖应用提供可访问的文本。应用能提供选区位置时，蓝点和译文浮窗显示在选中文字旁。只提供文字时，它们显示在鼠标松开处。扫描图片可先用其他工具提取文字。若快捷键已被其他程序占用，仍可点击蓝点翻译。

## 数据和本地部署

设置保存在当前用户的 `%LOCALAPPDATA%\Shiyi\settings.json`。API Key 使用 Windows DPAPI 按当前用户加密。拾译不保存原文、译文或翻译历史。

选中文字本身不会发出网络请求。触发查词时，如能读取原句，拾译会把所选词和紧邻它的句内文字一起发给配置的模型，用于判断句中义。较长的原句只取附近片段。识别为整句的选区直接送译。对于没有空格、词句界限不清楚的选区，模型会结合可用片段判断该显示词条还是译文。词条由配置的模型生成，发音在本机合成。要完全在本机翻译，请连接本机已运行的模型服务。

## 从源码构建

在项目目录中运行以下命令，生成的单个可执行文件位于 `dist\Shiyi.exe`。构建使用 Windows 自带的 .NET Framework 编译器和 WPF，无需下载 NuGet 包。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```
